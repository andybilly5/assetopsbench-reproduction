# 复现范围与偏差

## 实现范围

- ReAct 公共循环：模型决策、工具白名单与参数校验、错误反馈、步数上限和轨迹持久化。
- Single-Agent：一个 Agent 使用合并工具集。
- Agent-as-Tool：监督 Agent 调用领域 Agent，领域 Agent 在各自工具集上执行。
- Plan-Execute：规划 DAG、依赖执行、逐步复核和最终汇总；非法计划、失败节点及依赖跳过有明确状态。
- OpenAI 兼容后端与离线 ScriptedBackend；本仓库不包含模型权重或训练流程。
- 静态答案判分与 DeepSeek 六维判官，推理与评估分离。

## 工具集合

| 域 | 工具数 | 边界 |
|---|---:|---|
| IoT | 4 | 查询本地目录和遥测 |
| FMSR | 4 | 查询自建知识库，不是完整上游故障库 |
| TSFM | 7 | 确定性数值基线及能力说明，不是预训练 TSFM 权重推理 |
| Utilities | 6 | 公共检索与辅助操作 |
| WO | 15 | 自建合成工单查询 |
| Vibration | 8 | 无实测振动数据，明确返回 DataUnavailable |

CLI 默认六域共 44 工具。历史 V2 的 15 工具集合须加 `--no-utilities --no-wo --no-vibration`；V3 的 21 工具集合须加 `--no-wo --no-vibration`。TSFM 的 finetune 接口不代表实际训练了基础模型。

## 数据与实验可比性

备份中的公开场景为 152 条。历史覆盖划分为 80 条可执行子集（52 ready、28 generic），其余 72 条受公开数据或本地能力覆盖限制；应以当前 validate-data 输出核实覆盖状态，不能将该历史划分当作所有工具版本通用划分。

- 仅有 3 资产、45 传感器、136,805 条有效读数；缺失记录不是模型错误。
- 没有上游完整工单库、振动测点及预训练 TSFM 权重；相应工具能力不能宣称等价。
- Plan-Execute 使用执行后的逐步 Reviewer；与原论文的具体审查位置及实现存在差异。
- 领域 Agent 调用计数保留，但当前内层逐工具详细轨迹未完整持久化；审计时应说明这一限制。
- 原场景缺少 expected_answer，不能用静态判分或缺失的 ROUGE 参照答案计算真实完成率。
- 现有判官替换为 DeepSeek，不能直接对照论文的绝对分数。

## 判分定义

单次 pass 要求前五维均为 true 且 hallucinations 为 false。重复评判默认 5 次；有效票的通过比例严格大于 `0.5 + delta` 才通过，delta 默认 0。

单次 score 为前五维真值个数除以 5；有幻觉扣 0.2，下限为 0。最终 score 为有效评判得分均值，与投票 pass 分开计算。解析失败单独登记；全部解析失败则 score 为 None、passed 为 false。

对外报告须同时记录场景清单、工具集合、策略、模型、提示词、解码参数、步数预算、判官及失败数量。这里的 pass_rate 是本地口径下通过比例，不等同于论文所有指标。
